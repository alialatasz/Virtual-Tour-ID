Arsitektur Sistem: Virtual Tour 360 Benteng Pendem (Fort Willem I)

Aplikasi Virtual Tour 360 ini dibangun menggunakan arsitektur Modern Web Application (Single Page Application/SPA) yang berfokus pada kecepatan, rendering grafis 3D (WebGL) yang mulus, dan antarmuka pengguna (UI) yang sinematik.

Sistem ini menggunakan pendekatan Jamstack (JavaScript, API, Markup) yang jauh lebih cepat dan aman dibandingkan arsitektur tradisional.

1. Frontend (Antarmuka Pengguna)

  • Framework Utama: Next.js 14 (React.js)
    Mengatur state manajemen dan memecah UI menjadi komponen-komponen kecil yang bisa digunakan ulang (seperti Navbar, RoomCarousel, HistoryModal).
  • Styling & Desain: Tailwind CSS
    Menciptakan tema Cinematic Dark Glassmorphism secara responsif dan sangat ringan.
  • Animasi: Framer Motion & CSS Transitions
    Mengatur animasi Splash Screen dan transisi pergantian ruangan yang halus.

2. Mesin Virtual 360 (Core 3D Engine)

  • Engine Utama: Pannellum (WebGL)
    Pustaka berbasis WebGL murni yang super ringan untuk merender panorama 360 derajat.
  • Integrasi React Wrapper (PannellumViewer.tsx)
    Memiliki fitur khusus seperti Radar Minimap Dinamis (algoritma pelacakan rotasi 60fps) dan Gyroscope (mendeteksi pergerakan HP via DeviceOrientation API).

3. Backend & Database (Manajemen Data)

  • Database Lokal: lib/tourData.ts
    Data sejarah, koordinat rute, dan teks disimpan secara lokal (In-Memory). Memberikan kecepatan Zero-Latency tanpa perlu membuang waktu menunggu respon server database eksternal.
  • Arsitektur Serverless
    Siap di-hosting pada jaringan Serverless (seperti Vercel) yang akan mendistribusikan aplikasi ke CDN global.
